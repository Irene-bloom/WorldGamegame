# 小径分岔的花园 · The Garden of Forking Paths

一个基于博尔赫斯同名短篇的解谜探索游戏原型。

> 时间不是一条直线，而是一张**分岔的网**。每个抉择点，所有结局同时发生，各自分裂出新的时间线。
> 你继承了曾祖父崔朋留下的「花园」——一座所有时间线并存的时间迷宫。
> 要抵达它的「中心」，你必须学会**侧耳倾听邻近的时间线**，从别人的命运里推断出自己的答案。

## 核心机制：跨线观察推理

任何单一时间线里的信息都不完整。在花园的某些「观察点」，你能窥见邻近时间线里「另一个你」的下场——用这些信息，反推出自己这条线该怎么选。

## 技术栈

- Next.js 15 + React 19 + TypeScript + Tailwind CSS
- 纯前端，进度存 localStorage
- 第一版纯静态（谜题逻辑预先写死，保证可解、离线可玩），架构预留 AI 接口供以后润色叙事

## 本地运行

```bash
npm install
npm run dev
```

然后打开 http://localhost:3000 。

## 文档
